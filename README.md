# 梅课 · SEU 校园课表网页版

这是梅课网页版的编译产物仓库，包含公开网页、主题素材、字体许可和 GitHub Pages 部署工作流。

正式入口：https://everflora.github.io/MeiKe-web/

在 iPhone Safari 打开后，选择「分享 → 添加到主屏幕」。首次打开请保持联网，等待离线资源就绪后再离线使用。课表保存在本机浏览器，请定期导出 JSON 备份；可导入梅课手机 App 导出的课表。

当前提供课表、今天、校历、三套主题与奶蛋导航。学校登录功能打开学校官网；网页讨论室与课程组队尚未开放。

使用与隐私说明：[privacy.html](https://everflora.github.io/MeiKe-web/privacy.html)。反馈联系：[Everflora](https://github.com/Everflora)。本项目为学生开发工具，并非学校官方应用，学校安排以正式通知为准。

网页更新会显示「保存编辑后更新」，请先保存表单。清理网站数据可能删除本机课表；本仓库不保存同学导入的课表数据。
