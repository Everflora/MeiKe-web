梅课网页版

梅课是学生开发的校园课表工具，并非学校官方应用。学校安排以正式通知为准。

课表保存在你的设备

当前默认版本无需注册账号。课程、教师、教室、备注、外观设置以及导入前的课表副本保存在当前浏览器的 IndexedDB 中，不会被上传到 GitHub 仓库或梅课聊天服务器。本版本不启用广告和使用行为分析。

清理网站数据、隐私浏览、浏览器存储回收或更换网址，可能导致这些记录不可用。请定期在「我的」中导出 JSON 备份；从 Safari 切换到主屏幕应用时也建议先导出备份，以便在需要时恢复。你可以通过浏览器设置清除此站点数据。

离线与更新

首次访问需要联网下载页面、字体、主题素材与校历。离线资源就绪后，可断网打开和编辑已保存的课表。网页更新前请先保存正在编辑的内容；更新不会主动删除本地课表。离线缓存不包含聊天消息或学校账号。

学校网站与讨论室

学校选课、劳动教育、教务通知等入口在新窗口打开官方站点。登录凭据由学校网站处理，梅课网页不读取学校账号密码，也不会绕过浏览器隔离限制抓取登录后的页面。默认网页构建尚未开放课程聊天与组队。

托管服务

如部署到 GitHub Pages，GitHub 会为安全目的记录访问者 IP 等服务日志。请参阅 GitHub 隐私声明。这些托管日志与本机课表记录是不同的数据。

反馈与项目联系：Everflora 项目团队。有关课程安排请以学校正式通知为准。
